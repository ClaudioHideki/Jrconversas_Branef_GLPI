# Registro de decisões arquiteturais

Use [0000-template.md](0000-template.md) para uma decisão relevante. Numere pela próxima sequência livre, registre contexto, decisão, consequências e evidências. Estados: Proposta, Aceita, Rejeitada ou Depreciada.

Não marcar uma proposta como aceita sem a decisão correspondente. Preserve os documentos anteriores; para alterar uma decisão aceita, escreva uma nova que indique qual decisão substitui.

## Decisões deste bootstrap

- [0001-governanca-operacional-init](0001-governanca-operacional-init.md): adoção do INIT solicitado pelo usuário.
- [0002-intake-prazos-nativos-glpi](0002-intake-prazos-nativos-glpi.md): prazos atuais do GLPI, atributos na criação e limites da ativação automática.

- [0003-handoff-glpi-independente](0003-handoff-glpi-independente.md): transferência humana atômica e entrega GLPI posterior, sem bloquear atendimento.
- [0004-prioridade-explicita-bug](0004-prioridade-explicita-bug.md): prioridade definida na rota BUG conforme retorno documental aprovado em 18/11.

- [0007-nico-consumo-confirmado-limites-provedor](0007-nico-consumo-confirmado-limites-provedor.md): controle pelo provedor, teto local opcional e consumo incerto preservado.
